## 10. 작업 결정 전 자문

새로운 최적화/변경을 제안할 때:

1. **이 변경이 사용자 지시와 부합하는가?** → 지시 재확인
2. **측정 데이터가 있는가?** → 없으면 "측정 후 결정" 제안
3. **다른 파일/프로세스에 부작용은 없는가?** → 의존 관계 확인
4. **시간 비용 대비 이득이 명확한가?** → 수치로 제시
5. **되돌리기 어려운 작업인가?** → 사용자 확인 필수
