# 4. ML 이상탐지 방법론 — DCdetect 비지도 시계열 IDS

## 큰 그림: 왜 비지도 시계열 이상탐지인가
AIS는 선박의 위치·속도·식별 정보를 **AIVDM 평문 메시지**로 브로드캐스트한다. 인증·무결성 검증이 없어 허위 위치/속도/식별 정보가 삽입된 가짜 신호(AIS Spoofing)를 무방비로 수신한다. 이를 탐지하는 것이 본 IDS의 목표다.
**왜 비지도 학습인가**: 학습 데이터로 쓰는 Marine Cadastre AIS 데이터(NOAA·BOEM 운영)에는 정상/공격 레이블이 없다. 실제 스푸핑 공격 사례 수집도 제한적이고, 정상·비정상을 명확히 구분한 공개 데이터셋이 부족하다. 따라서 **정상 패턴만 학습하고 그로부터의 이탈 정도로 이상을 판단**하는 비지도 방식이 적합하다.
> → 우리 프로젝트에서의 의미: 레이블 없는 실데이터로 모델을 만들 수 있고, 학습 시 본 적 없는 신종 공격에도 원리상 반응할 수 있다.

### 핵심 메커니즘: 재구성 오차(Reconstruction Error)
- 오토인코더 계열 모델이 입력 시퀀스를 압축(Encoder)했다가 복원(Decoder)한다.
- 원본과 복원값의 **MSE(평균 제곱 오차)**를 이상 점수로 사용한다.
- 정상 시퀀스 → 잘 재구성 → MSE 낮음 / 이상 시퀀스 → 재구성 실패 → MSE 높음.
- 손실함수는 `MSE(재구성, 원본)` 최소화. 정상 데이터만으로 학습한다.
> → 의미: "정상을 얼마나 못 그려내는가"가 곧 이상 점수다. 임계값만 넘으면 이상 판정.

## 시계열 입력 구조 — 시퀀스와 베이스 12피처

### 시퀀스 단위
- 동일 MMSI(선박 고유번호)의 연속 AIS 신호 **10개(SEQ_LEN=10)를 하나의 시퀀스**로 묶어 학습/탐지한다.
- 즉 한 선박의 신호가 10개 모여야 탐지가 시작된다 (플러그인도 "MMSI당 10개 신호 누적 시 탐지").
- 입력 텐서 형태: `(B, T, F) = (배치, 10스텝, 12피처)`.

### 베이스 12피처 (고정)
원본 AIS 값 + Haversine·차분 기반 파생 피처로 구성된다.
| # | 피처 | 정의 / 탐지 의도 |
| 1 | `sog` | 속력(knots) — 물리적으로 불가능한 속도 |
| 2 | `cog` | 진행 방향(도) — heading과 조합해 방향 위조 |
| 3 | `heading` | 선수 방향(도), 511=미수신 — cog와 크게 다르면 스푸핑 의심 |
| 4 | `status` | 항행 상태 — SOG와 조합해 "정박 중 이동" 모순 |
| 5 | `dt` | 이전 신호와의 시간 차(초) — 비정상 신호 간격 |
| 6 | `dist_km` | Haversine 거리(km) — dt와 조합해 불가능한 이동(위치점프 핵심) |
| 7 | `cog_hdg_diff` |  |
| 8 | `sog_change` |  |
| 9 | `cog_hdg_change` |  |
| 10 | `speed_consistency` | `dist_km / (sog×dt/3600×1.852)` (정상≈1.0) — SOG 정상 보고하며 실제 위치를 다른 방향으로 옮기는 공격 |
| 11 | `lat_speed` | `(lat − prev_lat)/dt` — 위도 방향 이동 벡터 |
| 12 | `lon_speed` | `(lon − prev_lon)/dt` — 경도 방향 이동 벡터 |
> 참고: [CLAUDE.md](http://claude.md/)의 운영 베이스 12피처 목록과 표기가 약간 다르지만 핵심 12개 골격은 같다. 본 표는 자료([머신러닝.md](http://xn--vj1by9gn3bj3o.md/))의 피처 축소 결과(14→12) 기준이다.

### 전처리 파이프라인 (이상값 제거)
1. 9개 컴럼만 선택(`mmsi, base_date_time, lat, lon, sog, cog, heading, status, vessel_type`)
1. 위경도 범위 초과·SOG 음수 행 제거 (1차 필터)
1. MMSI 숫자 순 → 시간 순 정렬
1. MMSI별 신호 10개 미만이면 전체 제거 (최소 시퀀스 필터)
1. MMSI 단위 이상값 있으면 그 MMSI 전체 제거 (2차 필터)
1. 결측값 forward fill
1. 파생 피처 계산(`dt, dist_km, cog_hdg_diff` 등)
1. **위치 점프 MMSI 제거**: 최대 속도(50노트)+20% 여유 초과 시 MMSI 전체 제거
> → 의미: "정상"의 정의를 매우 보수적으로 잡아, 학습 데이터에 공격성 패턴이 섞이지 않게 한다.

## 메인 모델: DCdetect (Dual Attention)

### 기존 모델의 한계
LSTM/Transformer 기반 이상탐지는 **시간 축(temporal)만** 보고 **피처 간 관계(channel)는 무시**한다. 그래서 개별 피처는 정상인데 조합이 비정상인 **정교하게 위장된 이상**을 못 잡는다. DCdetect는 이를 **이중 어텐션**으로 해결한다.

### 두 관점의 어텐션을 동시에 학습
- **Channel-wise**: "피처들이 서로 어떤 관계인가?"
- **Patch-wise**: "시간 구간들이 서로 어떤 패턴인가?"

### 구조 4단계
1. **Channel-wise Attention**: 입력 `(B,10,12)`에 Multi-head Attention(head 수 = 피처 수 = 12). 각 피처가 다른 피처에 얼마나 주목하는지 학습. (예: 정상은 SOG↔dist_km 강한 상관, 이상은 SOG 높은데 dist_km 작음 → 어텐션 패턴 붕괴)
1. **Patchify**: 10스텝을 patch_size=2로 묶어 5개 패치. 각 패치 = 2스텝×12피처 = 24차원 → Linear로 d_model(64) 임베딩.
1. **Patch-wise Attention**: 5개 패치 간 Multi-head Attention. 출력 `(B, 5, 64)`. (이상이면 특정 패치에서 급변 → 어텐션 패턴 이상)
1. **Decoder**: `Linear(64→24) → reshape → (B,10,12)`. 원본과 비교해 `MSE = mean((재구성−원본)²)`.
> → 의미: DCdetect는 "피처 조합의 일관성"과 "시간 구간 패턴"을 동시에 보므로, 단일 값은 그럴듯하지만 함께 보면 모순인 스푸핑에 강하다.

### 보조 모델: TranAD (Self-Conditioning)
- 두 Decoder가 서로 조건을 주고받아 이상 시점의 오차를 **증폭**한다.
  - D1: `memory + x → o1` (1차 재구성)
  - D2: `memory + o1 → o2` (o1을 조건으로 한 2차 재구성)
- 정상이면 o1≈x → o2도 x에 수렴(MSE 낮음). 이상이면 o1≠x → o2가 더 혼란(오차 증폭, MSE 높음).
- **Adversarial 학습 스케줄**: 에포크 진행률 `n=epoch/total`이 커질수록 증폭 강도 증가.

### 앵상블
- 최종 점수 `score = 0.7 × MSE(DCdetect) + 0.3 × MSE(TranAD)`.
- score > threshold → 이상 판정.
- 장점: 오탐율 정밀 제어, 두 모델 기여도 조절. 단기 변화(TranAD)와 피처 조합/구간 패턴(DCdetect)을 상호 보완.
> 비고: 학회 논문집에서는 초기 단일 LSTM Autoencoder로 기술하지만, 현재 운용 모델은 DCdetect+TranAD 가중 앵상블이다. [CLAUDE.md](http://claude.md/) 기준 단일 메인 모델은 dcdetect다.

## 임계값(Threshold)과 탐지율 평가

### FP=1% 임계값
- 임계값 = **홀드아웃 정상 시퀀스 점수의 99퍼센타일** (상위 1%가 오탐).
- 탐지율 = 공격 시나리오 시퀀스 중 임계값 초과 비율.
- FP=5%, FP=10% 기준(95/90퍼센타일)도 동시 산출.
- 배포 threshold = 이 FP=1% 임계값과 동일 → 현장에서도 동일 오탐율 보장.
> → 의미: "오탐율을 1%로 고정했을 때 공격을 몇 % 잡느냐"가 핵심 비교 지표. FP를 고정해야 모델 간 공정 비교가 된다.

### MMSI 홀드아웃 / 데이터 분리
- FE 내부에서 `train_seqs`와 `holdout(정상, FP측정용)`을 분리.
- `--holdout_file` 옵션으로 학습 데이터와 **완전 분리된** FP 측정 파일 지정 가능.
- 정상 시퀀스 풀에서 샘플링(예: 3,000개)해 임계값을 산출.
> → 의미: 임계값을 학습에 쓰지 않은 정상 데이터로 잡아야 오탐율이 현장에서도 유지된다.

### 3개년 균형 데이터셋
- `ais_preprocessed_3yr.csv` (2023–2025, ~10.9 GB) — 연도 균형을 맞춘 3개년 데이터셋.
- 학습 MMSI 수는 `--max_mmsi`로 상한(예: 3000).
> → 의미: 단일 연도/단일 해역 편향을 줄여 다양한 정상 패턴을 학습. 논문도 "해역·선종·통신 환경에 따라 특성이 달라질 수 있다"며 다양 환경 추가 검증의 필요성을 한계로 명시.

## 피처 엔지니어링: Greedy Forward Selection
베이스 피처에 파생 피처를 하나씩 추가해 탐지율을 끌어올리는 **탐욕적 전진 선택** 알고리즘.

### 알고리즘
1. 현재 피처셋으로 베이스라인 학습 + 평가(FP=1/5/10).
1. 후보 피처를 **각각 하나씩** 추가 → 학습 → **목적점수** 계산.
1. 최고 목적점수 향상이 `--min_gain`(기본 +3.0pp) 이상이면 **1개 채택**.
1. 채택셋으로 **재학습(model_best)** → permutation importance + 최종 FP1/5/10 + threshold 산출 → 배포 export.
1. 오케스트레이터는 `--max_steps 1` → run(브랜치)당 1피처 채택 후 새 브랜치로 체이닝(dcdetect_001→002→…). 더 이상 +3.0pp 채택이 없으면 수렴 종료.

### 목적점수 (Objective)
- `목적점수 = 전체평균 + 1.0 × 약세평균` (FP=1% 기준).
- **약세 시나리오** = 베이스 탐지율 < 50%인 시나리오. 잘 못 잡는 쪽에 가중을 둡, 강한 시나리오만 더 강해지는 편향을 막는다.
> → 의미: 단순 평균 탐지율이 아니라 "못 잡던 공격을 얼마나 끌어올렸나"를 동시에 보상. 약점 보완형 피처가 채택되도록 유도.

### 주요 FE 후보 피처 (예)
`cog_change`(COG 변화량), `heading_change/heading_rate`(선수각 변화/율), `accel`(가속도 Δsog/dt), `status_change`, `anchor_suspicion`(정박의심), `speed_ratio`, `dist_speed_err/ratio`, `sog_vec_kn`, `lowspeed_crab`, `cog_move_diff`(COG vs 실이동방향 차이) 등.

## Permutation Importance (순열 중요도)
- 특정 피처값을 셔플(의미 제거)했을 때 탐지율이 얼마나 떨어지는지로 중요도를 측정.
- 표기: **음수가 클수록 중요** (제거 시 탐지율 하락폭). 예: `−13.43pp` = 제거 시 탐지율 13.4%p 하락.
- 두 관점 분석:
  - **정상 기준(ΔMSE↑)**: 정상 재구성에 중요한 피처 (예: `cog_hdg_change`, `cog_hdg_diff` 상위).
  - **이상 기준(ΔMSE↓)**: 실제 이상 탐지에 기여하는 피처 (예: `lon_speed`, `lat_speed`, `dist_km`).
> → 의미: 어떤 피처가 모델 탐지력을 떠받치는지 정량화. 채택 피처가 진짜 기여하는지 검증하고, 불필요 피처 제거 판단에 쓴다.

## 32개 공격 시나리오
이상 신호 발생기가 생성하는 합성 공격으로 탐지율을 평가한다. 6개 그룹·총 32개.
| 그룹 | 수 | 설명 |
| Basic | 4 | COG/HDG 불일치, 정박 중 이동, 속도 이상, 위치 점프 |
| FN | 4 | 룰 기반 탐지기 회피 설계 (예: FN3-COG경계, FN4-status) |
| D | 4 | ML 회피 1세대 (D1-LowSlow, D2-Temporal, D3-GradDrift, D4-Mimicry) |
| E | 5 | ML 회피 2세대 (E1-Smooth … E5-Shadow) |
| F | 7 | 고급 공격 (F1-FeatSmooth, F3-TrajStitch, F7-LSTMBeat 등) |
| G | 7 | 신종 시나리오 (예: G4-StatusFlicker, G5-ZigzagAccel) |

### 강점/약점 패턴 (반복 관측)
- **잘 잡힘**: 위치점프(100%), 속도이상(≈99.8%), FN1-dt점프(100%), D2/D3/E3/F4/F6(100%대).
- **만성 약세**: **D1-LowSlow(0%)**, FN4-status, FN3-COG경계, 정박이동, G4-StatusFlicker. 공통 원인은 **저속·정지·이산 status 기반 미세 조작** — sog/accel이 거의 0이라 재구성 오차가 정상과 구분되지 않음. 논문도 D1-LowSlow 탐지율 0%를 한계로 명시.
> → 의미: 동역학(가속·이동) 피처는 포화 상태. 약세를 깨려면 **저속 영역의 위치·상태 일관성**(status 전환 인코딩, 정지 구간 미세 표류량 등)으로 후보를 전환해야 한다는 진단이 반복된다.

## 중간발표 성능 서사 (시간순)
1. **초기 — 단일 LSTM Autoencoder**: 비지도 시계열, 임계값=훈련 데이터 하위 95% MSE. 속도 이상·위치 점프에 강하지만 저속 위장(D1)에 무력.
1. **논문(학회 논문집) 검증치**: 정상 시퀀스 MSE 0.000019 vs 공격 0.000021, 임계값 0.000020(정상 5,000개 기준 오탐율 5%). 위치점프 100%·속도이상 99.8%. 평균 탐지시간 239ms(실시간 가능성), 메모리 10.3%. 한계: D1-LowSlow 0%.
1. **피처 축소 14→12**: threshold 재조정으로 COG/HDG불일치 +12.0%p, 정박이동 +11.8%p, FN3 +21.4%p, D4-Mimicry +20.0%p, F3-TrajStitch +28.2%p 등 약세 시나리오 대폭 개선 (일부 E5-Shadow −13.0%p 트레이드오프).
1. **DCdetect+TranAD 0.7/0.3 앵상블(FP=5%)**: 평균 ≈88%. 정박이동 99.8%, E1-Smooth/F1/F3 100% 등. 단일 모델 대비 보완적 탐지 확인.
1. **자동화 FE 시대 (dcdetect_001~)**: Greedy 1피처 체이닝으로 13→24피처 확장. (참고: 이후 공식 freeze 수치는 Iter8 20피처 FP=1% **91.9%** — 발표 인용은 이 값만.)

### 모델 비교 스냅샷
- v0.1.0 릴리즈(FP=1%, 32시나리오): conv1d 68.3%, dcdetect 47.4%/홀드아웃F 65.6%, tranad 35.4%.
- 데모(5시나리오): conv1d/dcdetect/lstm/tcn 100%, usad 80%(정박중이동 미탐).
