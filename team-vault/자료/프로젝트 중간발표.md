프로젝트 설계 – 머신러닝 기반 탐지

https://www.gklibrarykor.com/3184/

● 머신러닝 기반 탐지

학습 알고리즘 선정

○ 머신러닝 학습 방법

■ 지도 학습 : 정답(Label)이 있는 데이터를 학습하는 방식

■ 비지도 학습 : 정답이 없는 데이터에서 스스로 패턴을 찾는 방식

■ 강화 학습 : 시행착오를 통해 보상(Reward)을 극대화하는 행동을 배우는 방식

○ Marine Cadastre Hub에서 제공하는 데이터는 별도의 정답(Label)이 구분되어 있지 않으므로 비지도 학습을 사용해야 함.

○ 더 정확한 탐지를 위해 시계열 데이터 기반으로 모델 학습 진행

- 시계열 데이터 : 시간의 흐름에 따른 순서로 정리된 데이터

프로젝트 설계 – 머신러닝 기반 탐지

● 머신러닝 기반 탐지

학습 알고리즘 선정

○ 비지도 학습 기반 시계열 데이터 이상치 탐지 알고리즘 : LSTM Autoencoder

■ 시계열 데이터 입력을 압축(Encoder)했다가 다시 복구(Decoder)하는 과정을 통해

MSE(Mean Squared Error, 평균 제곱 오차)를 계산

■ MSE값이 설정한 임계값보다 크면 이상치로 탐지

■ 임계값은 훈련 데이터의 하위 95% 부분의 MSE를 사용

■ 시뮬레이터를 통해 탐지율 확인하여 임계값 설정
