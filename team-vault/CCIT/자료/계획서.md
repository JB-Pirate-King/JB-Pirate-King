# 계획서

## 1. 요약
목표 : 선박에서 수신한 AIS(Automatic Identification System) 신호 기반의 공격을 분석·탐지하는 AIS 기반 IDS(Intrusion Detection System)를 설계·구현
- 목표: AIS 데이터 기반 이상 행위(스푸핑, Ghost ship, Flooding, 위치 위·변조 등) 탐지
- 언어: Python 중심 (수신 → 파싱 → 탐지 → 사용자 알림)

---


## 2. 기술적 배경

### 2.1 AIS 개요
AIS 는 선박 위치, 속도, MMSI(Maritime Mobile Service Identity,선박 고유번호**)**, 항로 등의 정보를 VHF(very high frequency, 초단파)로 브로드캐스트 송수신하는 시스템
- 메시지 구조 : ASCII 기반 NMEA 문장
- 특징:
  - 인증 없음
  - 암호화 없음
  - 브로드캐스트 기반
⇒  구조적으로 수신자는 무조건적인 신뢰를 가정하는 보안 취약점 내재

---


## 3. 위협 모델 정의

### 3.1 공격 시나리오
| 공격 유형 | 설명 | 탐지 대상 |
| Spoofing | MMSI 위조 | 동일 MMSI 다중 위치 |
| Ghost Ship | 존재하지 않는 선박 생성 | 비정상 MMSI |
| Flooding | AIS 대량 송신 | 초당 메시지 폭증 |
| Position Manipulation | 위치 점프 | 비현실적 이동속도 |

### 4.3 탐지 기준
탐지에 필요한 파생 변수:
| Feature | 설명 |
| ΔTime | 이전 메시지와 시간 차 |
| ΔDistance | 위치 변화 |
| Calculated Speed | 실제 이동 속도 |
| MMSI Frequency | 초당 송신 빈도 |
| Heading Variation | 방향 변화율 |

---


## 5. 탐지 기준 설계
예시)
- 동일 MMSI 1초 50개 이상 → Flooding 
- 동일 MMSI 10초 내 10km 이동 → Spoofing
- 속도 > 100 노트(200km/h) → 비정상 속도 (보통 최대가 30노트=55km/h)
- 일정 면적 내에 과도하게 많은 선박 수

## 6. 실험 시나리오 설계

### 6.1 Flooding 실험
- Python 스크립트로 NMEA 반복 송신
- 초당 100건 송신
- IDS 반응 분석

### 6.2 Ghost Ship 실험
- 존재하지 않는 MMSI 생성
- 위치 랜덤 생성
- 장기 지속 시 탐지 여부 확인
