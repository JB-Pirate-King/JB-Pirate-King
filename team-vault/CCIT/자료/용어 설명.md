## 요약
- **AIS**: 선박 위치·항해 정보를 자동 송수신하는 VHF(초단파,물리신호) 기반 시스템
- **AIVDM 메시지**: AIS 데이터를 NMEA 0183 형식으로 표현한 실제 전송 문자열
- **ECDIS / ECS**: 전자해도 기반 항해 시스템 (ECDIS는 표준·인증, ECS는 비표준)
- **AIS Spoofing**: AIS 데이터를 조작하여 가짜 선박 정보 생성 또는 변조 공격

## 1. AIS (Automatic Identification System)

### 개념
AIS는 선박 간 및 육상국과의 **자동 위치/상태 정보 교환 시스템**입니다.
VHF 대역을 사용하며, 충돌 방지와 해상 교통 관제를 위해 사용됩니다.

### 주요 전송 정보
- MMSI (선박 식별번호)
- 위치 (위도, 경도)
- 속도 (SOG), 침로 (COG)
- Heading
- 선박 이름, IMO 번호
- 항해 상태 (정박, 이동 등)

### 특징
- **Broadcast 기반 (one-to-many)**
- 암호화 없음 → 보안 취약
- 주기적 송신 (2~10초 단위, 상황에 따라 변동)

## 1-1. AIVDM 메시지

### 개념
AIS 데이터는 내부적으로 binary지만, 실제 전송은 **NMEA 0183 ASCII 문자열**로 변환됩니다.
이때 사용하는 메시지 타입이 **AIVDM**입니다.

### 구조 예시

```plain text
!AIVDM,1,1,,A,15Muq?001oJr>tpE>p4@4?wT0<0u,0*5C
```


### 필드 구조
| 필드 | 설명 |
| !AIVDM | 메시지 타입 |
| 1 | 총 메시지 수 |
| 1 | 현재 메시지 번호 |
| (빈값) | 시퀀스 ID |
| A | 채널 (A/B) |
| payload | AIS 데이터 (6-bit encoding) |
| 0 | fill bits |
| *5C | checksum |

### 핵심 포인트
- payload는 **6-bit ASCII encoding**
- 디코딩 → binary → AIS message type별 구조 해석 필요
- message type (1~27)에 따라 필드 완전히 달라짐

## 2. ECDIS (Electronic Chart Display and Information System)

### 개념
전자 해도를 기반으로 선박 항해 정보를 통합하여 보여주는 시스템입니다.
AIS, GPS, Radar 등 다양한 센서 데이터를 통합합니다.

### 기능
- 실시간 선박 위치 표시
- 항로 계획 및 경로 안내
- 위험 경고 (충돌, 좌초 등)
- 주변 선박(AIS) 표시

### 특징
- IMO 규격 준수 시 **종이 해도 대체 가능**
- 핵심 항해 시스템 (bridge의 중심)

---


## 2-1. ECS (Electronic Chart System)

### 개념
ECDIS와 유사하지만 **표준 인증이 없는 시스템**

### 차이점
| 구분 | ECDIS | ECS |
| 표준 준수 | IMO/IHO 준수 | 비표준 |
| 법적 인정 | 가능 (종이 해도 대체) | 불가능 |
| 사용 데이터 | ENC (공식 전자해도) | 비공식 해도 가능 |
| 용도 | 상선 필수 장비 | 보조 장비 |

## 3. AIS Spoofing

### 개념
AIS 메시지를 조작하여 **가짜 선박 정보 생성/변조**하는 공격

---


### 공격 방식

### 1. Fake Vessel 생성
- 존재하지 않는 MMSI 생성
- 가짜 위치/속도 송신

### 2. 위치 변조 (Position Spoofing)
- 실제 선박 위치를 조작
- 항로 이탈처럼 보이게 만듦

### 3. Replay Attack
- 과거 AIS 메시지 재전송

### 4. Identity Spoofing
- 다른 선박의 MMSI 도용

---


### 공격 원인 (핵심 취약점)
- 인증(Authentication) 없음
- 암호화 없음
- Broadcast 구조 → 누구나 수신/송신 가능

---


### 영향
| 대상 | 영향 |
| ECDIS | 가짜 선박 표시 |
| 항해 | 충돌 위험 증가 |
| 관제 시스템 | 잘못된 트래픽 분석 |
| 군사 | 기만 작전 가능 |

---


### 실제 사례
- 유령선(Ghost Ship) 생성
- 특정 해역에 수십 척 가짜 선박 표시
- 군사·정치적 혼란 유발

---


## 정리 (보안 관점 핵심)
- AIS는 **신뢰 기반 시스템 → 보안 취약**
- AIVDM은 **실제 공격 surface (문자열 조작 가능)**
- ECDIS는 **공격 결과가 시각적으로 나타나는 종착지**
- AIS Spoofing은 **IDS 연구 주제로 매우 적합**
