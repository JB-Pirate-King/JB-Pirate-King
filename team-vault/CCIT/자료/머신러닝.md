  피쳐 축소 했음  (12개)
  - sog: CSV 원본값 / 가장 직접적인 이상 신호, 물리적으로 불가능한 속도 탐지
  - cog: CSV 원본값 / heading과 조합해 이동 방향 위조 탐지
  - heading: CSV 원본값 (511=미수신) / cog와 크게 다르면 스푸핑 가능성
  - status: CSV 원본값 / SOG와 조합해 "정박 중인데 이동" 같은 모순 탐지
  - dt: 현재 - 이전 base_date_time (초) / 비정상적으로 짧거나 긴 신호 간격 탐지
  - dist_km: Haversine 공식으로 두 좌표 간 거리 (km) / dt와 조합해 물리적으로 불가능한 이동 탐지
  - cog_hdg_diff: |cog - heading|, 180 초과 시 360에서 빼기 (heading=511이면 -1.0) / 항해 중 COG≈HDG가 정상, 크게 다르면 방향 위조
  - sog_change: |sog(t) - sog(t-1)| / 선박은 급격한 가속/감속 불가, 순간 급변 시 속도 스파이크 탐지
  - cog_hdg_change: |cog_hdg_diff(t) - cog_hdg_diff(t-1)| / cog_hdg_diff의 순간 변화로 주기적 진동 패턴 탐지
  - speed_consistency: dist_km / (sog × dt / 3600 × 1.852) / 정상≈1.0, SOG는 정상 보고하면서 실제 위치를 다른 방향으로 이동하는 공격 탐지
  - lat_speed: (lat(t) - lat(t-1)) / dt / 위도 방향 이동 벡터, 특정 방향으로만 드리프트하는 공격 탐지
  - lon_speed: (lon(t) - lon(t-1)) / dt / 경도 방향 이동 벡터, lat_speed와 쌍으로 이동 방향 이상 탐지

# 현재 모델
  DCdetect(70%) + TranAD(30%) 가중 평균 앙상블 모델 사용

### 배경
    기존 시계열 이상 탐지 모델들의 문제:
    - LSTM/Transformer 기반 모델은 **시간 축(temporal)** 만 봄
    - 피처 간 관계(channel)는 상대적으로 무시
    - 정교하게 위장된 이상(개별 피처는 정상, 조합이 비정상)을 못 잡음
    DCdetect는 이 문제를 **이중 어텐션(Dual Attention)** 으로 해결.

---


### 핵심 개념: Association Discrepancy 아님, Dual Attention
    TranAD/Anomaly Transformer의 Association Discrepancy와 다름.
    DCdetect는 **두 관점의 어텐션을 동시에 학습**:
    `Channel-wise : "피처들이 서로 어떤 관계인가?"
Patch-wise   : "시간 구간들이 서로 어떤 패턴인가?"`

---


### 구조 상세
    **Step 1: Channel-wise Attention**
    `입력: (B, T, F) = (배치, 10스텝, 12피처)

Multi-head Attention (head 수 = 피처 수 = 12)
→ 각 피처가 다른 피처들에 얼마나 주목하는지 학습

예시:
  정상: SOG ↔ dist_km 강한 상관 (빠르면 거리 큼)
  이상: SOG 높은데 dist_km 작음 → 어텐션 패턴 붕괴

출력: (B, T, F) — 피처 간 관계 반영된 표현`
    **Step 2: Patchify**
    `시퀀스 10스텝 → patch_size=2 → 5개 패치

[t0,t1] [t2,t3] [t4,t5] [t6,t7] [t8,t9]
  패치1   패치2   패치3   패치4   패치5

각 패치 = 2스텝 × 12피처 = 24차원 벡터
→ Linear 레이어로 d_model(64)차원 임베딩`
    **Step 3: Patch-wise Attention**
    `5개 패치 간 Multi-head Attention

예시:
  정상: 패치 간 속도/방향 변화가 완만
  이상: 특정 패치에서 급격한 변화 → 어텐션 패턴 이상

출력: (B, n_patches, d_model) = (B, 5, 64)`
    **Step 4: Decoder (재구성)**
    `Linear(64 → 24) → reshape → (B, 10, 12)

원본 입력과 재구성 결과 비교
MSE = mean((재구성 - 원본)²)`
    **전체 흐름:**
    `(B,10,12)
    ↓
Channel Attention  ← 피처 간 관계
    ↓
(B,10,12)
    ↓
Patchify → (B,5,24) → Linear → (B,5,64)
    ↓
Patch Attention    ← 구간 간 패턴
    ↓
(B,5,64)
    ↓
Decoder → (B,10,12)
    ↓
MSE 계산`

---


### 학습 방식
    **비지도 학습 (Unsupervised)**
    `정상 데이터만으로 학습
손실함수: MSE(재구성, 원본) 최소화

정상 시퀀스 → 잘 재구성 → MSE 낮음
이상 시퀀스 → 재구성 실패 → MSE 높음`
    **임계값 설정:**
    `정상 데이터 전체 score 분포
→ 95 퍼센타일 = threshold
→ 상위 5%만 이상 판정`
    **배경**
    기존 Transformer 기반 이상 탐지 문제:
    - 단순 재구성만으로는 정상/이상 MSE 차이가 작음
    - 이상 시점의 오차를 **증폭**시키는 메커니즘이 없음
    - 짧은 시퀀스(window=10)에서 성능이 제한적
    TranAD는 두 가지로 해결:
    1. **Self-Conditioning**: 두 Decoder가 서로 조건을 주고받아 이상 오차 증폭
    1. **Adversarial 학습 스케줄**: 에포크가 진행될수록 증폭 강도 높아짐

---

    **핵심 개념: Self-Conditioning**
    `일반 AE:
  입력 x → Encoder → Decoder → 재구성 o
  MSE(o, x) 최소화

TranAD:
  입력 x → Encoder → memory
  D1: memory + x  → o1 (1차 재구성)
  D2: memory + o1 → o2 (2차 재구성, o1을 조건으로)

정상 시퀀스:
  o1 잘 재구성됨
  o2는 좋은 o1 보고 더 잘 재구성됨
  → MSE 낮음

이상 시퀀스:
  o1 재구성 실패
  o2는 잘못된 o1 보고 더 혼란
  → 오차 증폭 → MSE 높음`

---

    **구조 상세**
    **Step 1: Input Projection + Positional Encoding**
    `입력: (B, T, F) = (배치, 10스텝, 12피처)

Linear(12 → 64)     ← 피처 차원 확장
+ Positional Encoding ← 시간 순서 정보 주입

PE(pos, 2i)   = sin(pos / 10000^(2i/64))
PE(pos, 2i+1) = cos(pos / 10000^(2i/64))

출력: (B, 10, 64)`
    **Step 2: Transformer Encoder**
    `Self-Attention:
  각 시점이 다른 시점들에 얼마나 주목하는지 학습
  "t=5 시점의 이상이 t=3 시점과 관련있는가?"

Multi-head Attention (nhead=4)
Feed-Forward Network (dim=128)
LayerNorm + Residual

출력: memory (B, 10, 64)
      → 시퀀스 전체의 맥락 정보 압축`
    **Step 3: Decoder D1 (1차 재구성)**
    `입력:
  tgt = PE(Linear(x))  ← 원본 시퀀스
  memory               ← Encoder 출력

Cross-Attention:
  tgt가 memory에 주목 → 맥락 반영해서 재구성

출력: o1 (B, 10, 12)  ← 1차 재구성`
    **Step 4: Decoder D2 (2차 재구성, Self-Conditioning)**
    `입력:
  tgt = PE(Linear(o1))  ← 1차 재구성 결과
  memory                ← 동일한 Encoder 출력

Cross-Attention:
  o1을 조건으로 다시 재구성 시도

출력: o2 (B, 10, 12)  ← 2차 재구성

핵심:
  정상이면 o1 ≈ x → o2도 x에 가까움
  이상이면 o1 ≠ x → o2는 더 멀어짐`
    **전체 흐름:**
    `(B,10,12)
    ↓
Input Proj + PE → (B,10,64)
    ↓
Transformer Encoder
    ↓
  memory (B,10,64)
    ↙              ↘
D1(memory, x)    D2(memory, o1)
    ↓                  ↓
   o1 (B,10,12)    o2 (B,10,12)`

---

    **학습 방식: Adversarial 스케줄**
    **두 Decoder를 별도 Optimizer로 학습:**
    `n = epoch / total_epochs  (0~1로 증가)

L1 (θenc + θD1 업데이트):
  = (1/n) × MSE(o1, x) + (1-1/n) × MSE(o2, x)

L2 (θenc + θD2 업데이트):
  = (1/n) × MSE(o1, x) − (1-1/n) × MSE(o2, o1)`
    **에포크별 학습 변화:**
    `초반 (n 작음, 1/n 큼):
  L1 ≈ MSE(o1, x)   → D1이 재구성 잘 하도록
  L2 ≈ MSE(o1, x)   → D2도 재구성 따라가도록
  → 정상 패턴 학습에 집중

후반 (n 커짐, 1-1/n 큼):
  L1 += MSE(o2, x)  → D2도 x에 가까워야
  L2 -= MSE(o2, o1) → D2가 o1과 달라야 (adversarial)
  → 이상 시점 오차 증폭에 집중`
    **왜 adversarial인가:**
    `L2의 − MSE(o2, o1) 항:
  D2가 o1과 달라지도록 학습
  → 정상이면 o1 ≈ x 이므로 D2도 x에 수렴 (문제없음)
  → 이상이면 o1 ≠ x 이므로 D2가 더 멀어짐 (오차 증폭)`
    score = 0.7 × MSE(DCdetect) + 0.3 × MSE(TranAD)
score > threshold → 이상 판정
    장점:
오탐율을 원하는 값으로 정밀 제어 가능
