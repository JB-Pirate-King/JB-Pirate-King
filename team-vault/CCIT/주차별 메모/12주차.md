## FE 내부 (`feature_engineer.py`)

```plain text
load_raw_seqs (캐시)  →  train_seqs + holdout(정상, FP측정용)
        │
        ▼
[베이스라인]  현재 피처셋 학습(DCdetector AE) → 평가
   재구성오차 점수 → 정상 99%ile = FP1% 임계값
   32 시나리오 탐지율 → 목적점수(전체평균 + 약세평균)
        │
        ▼
[Greedy] 후보 10개 각각:
   [현재+후보] 학습 → 평가 → 목적점수
   gain = 후보 - 베이스
   최고 gain > +3.0 ?  → 채택 1개  (아니면 수렴)
        │  (채택됨)
        ▼
[재학습] 채택셋으로 model_best 새로 학습
   → 순열중요도 + 최종 FP1/5/10 + threshold
   → export: model.onnx / scaler.json / threshold.txt
```
