# 10주차

## **지도 학습**

### **모델: ModernTCN**
- Temporal Convolutional Network(TCN) 기반 시계열 분류 모델
- AIS 신호 시퀀스(연속된 N개)를 입력받아 **이상일 확률(0~1)** 출력
- 출력값이 임계값(threshold) 초과 시 이상으로 판정

### **학습 방식**
- **이진 분류** (정상 0 / 이상 1) 
- 손실함수: Binary Cross-Entropy
- 입력: 12개 피처 × N개 시퀀스 (행렬)
- 정상 데이터: 실제 AIS CSV 19GB에서 스트리밍 샘플링
- 이상 데이터: 25개 시나리오로 합성 생성, 정상:이상 = 1:1 밸런싱

# 탐지 순서 
| **항목** | **내용** |
| **룰** | 첫 메시지부터 즉시 발동, 1회 경보 후 반환 |
| **ML seq5** | 5번째 메시지부터 탐지 시작 (~50s) |
| **ML seq10** | 10번째 메시지부터 탐지 시작 (~100s) |
| **경보 우선순위** | 룰 → ML seq5 → ML seq10 순 (먼저 걸리면 반환) |
| **시퀀스 리셋** | dt > 600s(10분) 공백 시 ML deque 초기화 |
| **중복 필터** | dt < 1s 메시지는 무시 |
| **이력 크기** | MMSI당 MAX_HISTORY개 유지 |
