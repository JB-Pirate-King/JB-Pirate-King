위 링크에서 데모에 쓸 데이터 찾음

아키텍처 구조도짜오고 ML 추가할 계획 넣어보기
- 구조도

```bash
[ 1. AIS 신호 수신 ]
  - 선박 신호 수집
          │
          ▼
[ 2. NMEA 메시지 해석 ]
  - AIVDM 메시지 디코딩
  - 주요 필드 추출
    (MMSI, 위치, 속도, 방향, 시간)
          │
          ▼
[ 3. 데이터 가공 / 특징 생성 ]
  - 위치 변화량 계산 (이동 거리)
  - 속도 변화 (가속/감속)
  - 방향 변화 (회전 정도)
  - 시간 간격 정리 
  - 선박별 데이터 묶기 (MMSI 기준)
          │ 
          ├───────────────┐
          ▼               ▼
[ 4-1. 룰 기반 탐지 ]   [ 4-2. ML 이상 탐지 ]
  - 비정상 MMSI         - 정상 패턴 학습
  - 비정상 속도         - 패턴 벗어나면 이상 판단
  - 순간 이동           - 입력:   
  - 포맷 오류            * 위치 변화
  - 비정상 빈도          * 속도 변화
                         * 방향 변화
                        - 출력:
                          이상 점수 (0~1)
          │               │
          └───────┬───────┘
                  ▼
[ 5. 최종 판단 ]
  - 룰 탐지 → 확정 공격
  - ML 점수 초과 → 이상 탐지
                  │
                  ▼
[ 6. 경고 및 로그 저장 ]
  - 공격 유형 기록
  - JSON 로그 저장
                  │
                  ▼
[ 7. 시각화 ]
  - 이상 행위 강조 표시
```
