# 통합 생태계 맵

## 개요
7개 서비스를 연결한 CCIT 프로젝트 통합 자동화 생태계입니다. 각 서비스의 특성에 맞게 역할을 분담하고, 자동화 흐름으로 연결합니다.

---


## 서비스별 역할
| 서비스 | 역할 | 특성 |
| **Notion** | 구조화 기록 (Single Source of Truth) | 공식 문서, 주차별 메모, 의사결정 기록 |
| **Obsidian** | 로컬 지식 베이스 | 오프라인 검색, 개인 메모, 그래프 뷰 |
| **Discord** | 실시간 알림 & 팀 소통 | 자동화 알림, 빠른 공유, 비공식 채널 |
| **Slack** | 공식 팀 커뮤니케이션 | 과제 관련 공식 채널, 멘토 소통 |
| **Google Drive** | 파일 저장소 | 바이너리 파일, 모델 파일, 공유 자료 |
| **Google Sheets** | 수치 추적 허브 | ML 성능 지표, 작업 목록, 대시보드 |
| **Claude Code** | AI 오케스트레이터 | 모든 서비스 연결, 자동화 실행 |

---


## 자동화 흐름

### 🔄 매일 오전 9시 (Windows 작업 스케줄러)
Notion → Obsidian 동기화
- CCIT 주차별 메모 11개 페이지 자동 다운로드
- Markdown으로 변환 후 `C:\Obsidian Vault\CCIT\` 저장
- Discord #알림봇 채널에 동기화 결과 전송

### 📊 ML 학습 완료 시 (수동)
Pipeline 결과 → Google Sheets 업데이트
- `D:\ais_output\pipeline\` CSV → 🤖 ML 모델 성능 시트
- Claude Code가 직접 시트 수정

### 📝 주간 업데이트
- Notion에 주차별 메모 작성
- 자동 동기화로 Obsidian에 반영
- Google Sheets 작업 목록 상태 업데이트
