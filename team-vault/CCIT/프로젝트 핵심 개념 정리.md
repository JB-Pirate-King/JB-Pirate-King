## 프로젝트 목표
선박 AIS(Automatic Identification System) 데이터에서 **이상 행동을 탐지**하는 IDS(Intrusion Detection System).
- **입력**: AIS 메시지 (AIVDM) → 12개 피쳐로 추출
- **출력**: 정상 / 이상 판정 (anomaly score)
- **배포**: OpenCPN 플러그인으로 실시간 동작

---


## 12개 입력 피쳐 (SEQ_LEN=10)
| 피쳐 | 설명 |
| `sog` | Speed Over Ground (속도) |
| `cog` | Course Over Ground (진행 방향) |
| `heading` | 선수 방향 |
| `status` | 항해 상태 (0=항해 중, 1=정박 등) |
| `dt` | 이전 AIS 메시지와의 시간 차(초) |
| `dist_km` | 이전 위치와의 거리(km) |
| `cog_hdg_diff` | COG와 Heading의 차이 |
| `sog_change` | 속도 변화량 |
| `cog_hdg_change` | 방향 변화량 |
| `speed_consistency` | 속도/거리 일관성 |
| `lat_speed` | 위도 방향 속도 |
| `lon_speed` | 경도 방향 속도 |

## ML 모델 구조 (11종 학습 완료)

### 비지도 (Unsupervised) — 재구성 오차 기반
정상 시퀀스만으로 학습. 이상 시퀀스는 재구성 오차(MSE)가 threshold를 초과.
| 모델 | 핵심 구조 | 강점 |
| **conv1d** | Conv1D AE | 지역 패턴 탐지, ONNX 안정 |
| **tranad** | Transformer 자기조건화 | 시간 의존성 |
| **dcdetect** | 이중 어텐션 | 정교한 위장 공격 탐지 |
| **usad** | 적대적 AE | 디코더간 불일치 활용 |
| **lstm** | LSTM AE | 순차적 패턴 |
| **tcn** | 확장 인과 컨볼루션 | 다양한 receptive field |
| **anomtrans** | 연관 불일치 | KL 발산 기반 |
| **iforest** | Isolation Forest + AE | 분포 기반 필터링 |
| **dagmm** | 가우시안 혼합 AE | 잠재공간 클러스터링 |
| **deepsvdd** | Deep SVDD | 초구 경계 학습 |
| **timesnet** | 시간-주파수 변환 | 주기 패턴 탐지 |

### 지도 (Supervised) — 별도 레이블링 필요
| 모델 | 핵심 | 비고 |
| **ModernTCN** | 시간적 CNN | Seq5에서 98.8% 탐지율 (FPR 0.1%) |

## 평가 시나리오 (32개)
| 그룹 | 수 | 역할 |
| Basic (A) | 4개 | COG/HDG 불일치, 정박이동, 속도이상, 위치점프 |
| FN | 4개 | 규칙 기반 탐지기 회피용 |

| E | 5개 | ML 모델 회피 시도 2세대 |
| **F (holdout)** | 7개 | 고급 공격 — 학습 제외 |
| **G (holdout)** | 7개 | 새로운 홀드아웃 |
