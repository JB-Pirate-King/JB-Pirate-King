`자료*`, `CCIT*` 경로는 자동 생성되는 읽기 전용 미러다. 원본(SSOT)은 Notion의 `홈 > 자료`, `CCIT` 두 트리이며, 해당 파일을 직접 수정해도 다음 동기화(매일 09:00/18:00) 때 덮어써진다.

루트의 `README.md`, `SETUP-팀원.md`, `발표 마스터플랜.md`, `발표 서사 - LLM 파이프라인.md`는 수동 관리 파일로 동기화 대상이 아니다.

4. `자료/LLM 동작 방식 — 위키·LangGraph·MCP.md` — LLM 4중 활용 구조
5. 심화·이력 자료는 `CCIT/` (주차별 메모, 취약점 리포트 원문, 선행 논문)

| 발표 방향 — LLM 기반 파이프라인 서사 | 루트 `발표 서사 - LLM 파이프라인.md` (전체판) |

## 알려진 잔재 (참고)

- 과거 동기화가 남긴 고아 파일이 일부 존재할 수 있다 (`(1)` 접미사 파일 등, frontmatter의 `last_synced`가 오래된 것). 최신 `last_synced` 파일이 정본이다.
- 본문의 `첨부(미변환)` 표기는 Notion에만 있는 원본 파일을 뜻한다. 과거 동기화분에 남아 있는 긴 S3 URL은 만료된 임시 링크이므로 무시한다.

## 동기화 동작

- 발행 PC가 매일 09:00 / 18:00에 Notion `자료`, `CCIT` 트리를 Markdown으로 변환해 이 폴더에 commit 후 `develop`에 push한다 (`C:\scripts\notion_team_vault_sync.py`).
- PDF/DOCX/PPTX/XLSX 첨부는 자동으로 `.md` 변환되어 별도 파일로 저장되고, 이미지는 각 폴더 `_assets/`에 저장된다.

## 팀원 사용법

코드 repo를 평소처럼 `develop`으로 clone/pull 하면 이 폴더도 같이 업데이트된다. Obsidian에서 `team-vault/` 폴더를 볼트로 열면 된다. 상세: [SETUP-팀원.md](SETUP-팀원.md)
